# 反馈问题

## 1. 反馈前

- 先检索本文档与仓库根目录 `README.md`、`AGENTS.md`。
- 确认问题属于当前保留能力；已删除模块（JT1078/FTP、ABL、流代理、推流、`/api/sy`、地图）不在维护范围。
- 平台级联处于冻结观察期，相关问题先记录，不承诺修复。

## 2. 反馈内容

- 现象、复现步骤、期望结果。
- 环境：JDK 17、MySQL 8.4、Redis、ZLM 版本与 profile。
- 日志片段：`logs/wvp-*.log`，删除密码、Token、设备口令、ZLM secret 后再提供。

## 3. 提交方式

- 提交到项目仓库 issue，或联系项目维护人。
- 不在文档、截图、日志中暴露真实口令与密钥。
