# 岸端企业平台（GB28181 视频底座）

> 当前为清理后的视频与设备底座，不是完整岸端企业平台 | 更新日期：2026-11-06
>
> 项目级说明以仓库根目录 `README.md` 与 `AGENTS.md` 为准；本文档站只描述当前保留能力。

## 1. 定位

- 基于 GB28181 的设备接入、通道管理、目录查询、实时点播、历史回放、对讲/广播、PTZ。
- ZLMediaKit 媒体节点、云录像、录像计划、录像下载。
- 设备告警、移动位置、用户/角色/API Key、日志。
- 当前没有前端工程；管理接口通过 Knife4j/OpenAPI 调试。
- GB28181 平台级联处于冻结观察期，不作为当前交付能力。

## 4. 快速开始

```bash
mvn -q -DskipTests compile
mvn spring-boot:run -Dspring-boot.run.profiles=dev,local
```

- 默认 HTTP 18080、SIP 8116；ZLM HTTP 9092（以本地配置为准）。
- 数据库初始化：`数据库/3.0.0/初始化-mysql-3.0.0.sql`。
- 首次启动设置 `WVP_ADMIN_PASSWORD`；真实口令只放本地未跟踪配置。
